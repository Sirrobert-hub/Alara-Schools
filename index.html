Core System Modules

Built to compete with national NEMIS-integrated ERPs.

Excel-Like Marks Entry

Keyboard navigation (Tab, Enter), auto-save, missing mark alerts, and instant 8-point KNEC grade calculation.

Report Cards & Transcripts

Verified printable PDF forms with school letterhead, student profile photos, teacher remarks, and QR code security blocks.

Visual Performance Analytics

Chart.js multi-axis graphs, grade distribution histograms, subject difficulty indices, and KJSEA predictions.

Fee Accounting & Receipts

Grade-level fee structures, student ledgers, payment recording (M-Pesa, Bank Deposit), and defaulters lists.

CSV Bulk Data Engine

One-click bulk import of learners and educators via CSV with validation previews and downloadable templates.

Role-Based Security & Audit

Dedicated persona dashboards for Admin, Principal, Deputy, Class Teacher, Subject Teacher, and Parent Portal.
